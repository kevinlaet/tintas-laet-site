# Links com UTM — cola aqui toda vez que for postar

Serve pra qualquer link que aponta **pro site** (linktree, home, catálogo). Link direto de WhatsApp (`wa.me/...`) não precisa disso.

Troca só o `SUBSTITUIR` pelo assunto do post daquele dia (sem espaço, sem acento, usa hífen). O resto do link fica sempre igual.

## Bio do Instagram
```
https://tintaslaet.com/?utm_source=instagram&utm_medium=bio&utm_campaign=perfil
```
(esse não muda — é fixo, pode deixar salvo na bio)

## Story do Instagram
```
https://tintaslaet.com/?utm_source=instagram&utm_medium=story&utm_campaign=SUBSTITUIR
```

## Status do WhatsApp
```
https://tintaslaet.com/?utm_source=whatsapp&utm_medium=status&utm_campaign=SUBSTITUIR
```

## Post no Facebook
```
https://tintaslaet.com/?utm_source=facebook&utm_medium=post&utm_campaign=SUBSTITUIR
```

## Exemplos de campanha
- `sorteio-agosto`
- `promo-latex`
- `abertura-loja6`
- `carrossel-27-08`

## Onde ver o resultado
Google Analytics → Relatórios → Aquisição → Aquisição de tráfego. O clique aparece como `instagram / story`, `whatsapp / status`, etc — em vez de cair em "(direct)/(none)".
